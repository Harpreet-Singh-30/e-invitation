```typescript
- Date formatting with date-fns

- CSS animations with keyframes
```

### Design System:
```css
Colors:
- Royal Maroon: red-900, amber-400, gold gradients
- Modern Floral: pink-400, rose-400, purple-400
- Classic Gold: amber-600, yellow-500, cream backgrounds

Typography Scale:
- Couple Names: 6xl → 7xl → 8xl (responsive)
- Section Headers: 5xl → 6xl → 7xl
- Body Text: xl → 2xl → 3xl
- Supporting: sm → base → lg

Spacing System:
- Section padding: py-24 (6rem)
- Card padding: p-8 → p-10
- Gaps: space-y-12 (3rem)
```
