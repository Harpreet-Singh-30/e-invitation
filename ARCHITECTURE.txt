│                                                             │
│  1. BROWSE                                                 │
│     GET /api/templates → Available templates               │

│  2. ORDER                                                  │

│     ↓                                                      │

│                                                            │
│  3. PAY                                                    │

│     ↓                                                      │
│     Payment record created (PENDING)                       │
│                                                            │
│  4. VERIFY (Admin)                                         │
│     POST /admin/payments/:id/verify                        │
│     ↓                                                      │
│     Order state: DRAFT → PREBOOKED/PURCHASED               │
│     Template status: AVAILABLE → RESERVED/SOLD             │
│     Generate edit token (256-bit, hashed)                  │
│     Send email with edit link ✉️                          │
│                                                            │
│  5. EDIT                                                   │
│     GET /api/edit/:token/site → Load data                  │
│     PUT /api/edit/:token/site → Save changes               │
│     POST /api/edit/:token/assets → Upload images           │
│                                                            │
│  6. PUBLISH                                                │
│     POST /api/edit/:token/slug → Claim subdomain           │
│     POST /api/edit/:token/publish → Go live!               │
│     ↓                                                      │
│     Order state: PURCHASED → PUBLISHED                     │
│     Site is_online: true                                   │
│                                                            │
